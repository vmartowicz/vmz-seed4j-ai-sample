### Exemple 0 - Niveau simple
```
Plateforme de réservation

Contexte :
Un utilisateur réserve un créneau pour un service.

Règles métier :
- La réservation peut être modifiée ou annulée.
- Un SMS de rappel est envoyé la veille.

Opérations nécessaires :
- réserver un créneau ;
- consulter une réservation ;
- modifier le créneau d'une réservation ;
- annuler une réservation.
```
