### Exemple 1 - Niveau simple
```
Application bancaire

Contexte :
Je veux gérer ldes compte bancaires.

Règles métier :
- un compte peut recevoir des virements
- un compte peut effectuer des paiements
- le solde d'un compte ne peut pas être négatif
- Chaque opération génère un événement d'audit

Opérations nécessaires :
- Ouvrir un compte
- Consulter le solde d'un compte
- Recevoir un virement sur un compte
- Effectuer un paiement depuis un compte
- Consulter l'historique des opérations d'un compte
```
