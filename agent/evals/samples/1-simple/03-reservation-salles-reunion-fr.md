### Exemple 2 - Niveau simple
```
Je veux gérer les réservations de salles de réunion.

Contexte :
Mon entreprise a 10 salles de réunion.

Règles métier :
- Une salle peut être réservée par créneau d'une heure.
- Pas de double réservation.

Opérations nécessaires :
- Créer une salle de réunion
- Créer une réservation
- Annuler une réservation
- Voir toutes mes réservations en cours
```
