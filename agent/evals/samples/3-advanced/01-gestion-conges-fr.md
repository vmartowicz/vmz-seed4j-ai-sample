### Exemple 5 - Niveau avancé
```
Je veux gérer un application de gestion de congés pour PME.

Contexte :
Mon entreprise est une PME d'environ 50 salariés.

Règles métier :
- 25 jours de congés payés par an
- Congés par demi-journée ou journée
- Délai de 15 jours recommandé
- Maximum 3 personnes en congé simultanément dans une équipe

Opérations nécessaires :
- Employé : demander, consulter son solde
- Manager : valider/rejeter
- RH : gérer les soldes
- Notifications par email lors des validations.
```
